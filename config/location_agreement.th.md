# การใช้ตำแหน่งของคุณใน iScale

iScale สามารถใช้ตำแหน่งของโทรศัพท์หรือแท็บเล็ตของคุณ เพื่อระบุตำแหน่งหลุมบ่อได้แม่นยำขึ้น **การใช้ตำแหน่งเป็นทางเลือก** หากคุณไม่ยินยอม ฟังก์ชันอื่นของ iScale ยังใช้ได้เหมือนเดิม: คุณปักหมุดหลุมบ่อได้โดยแตะบนแผนที่ และวิดีโอที่บันทึกจะใช้ความสูงของกล้องกำหนดขนาดแทน GPS ไม่มีใคร รวมถึงผู้ดูแลระบบของบริษัท ให้ความยินยอมแทนคุณได้

## ข้อมูลที่ iScale เก็บ
- ตำแหน่ง GPS ของอุปกรณ์ (ละติจูดและลองจิจูด) ความแม่นยำเป็นเมตร และเวลา
- ระหว่างที่คุณบันทึกการขับใน iScale: เส้นทาง GPS ประมาณวินาทีละหนึ่งตำแหน่ง ซึ่งผูกกับวิดีโอนั้น
- เก็บเฉพาะขณะที่ iScale เปิดอยู่บนหน้าจอเท่านั้น iScale ไม่ติดตามคุณเมื่อปิดแอปหรือแอปอยู่เบื้องหลัง

## วัตถุประสงค์ (ฐานทางกฎหมาย: ความยินยอมของคุณ ตามมาตรา 19 พ.ร.บ. คุ้มครองข้อมูลส่วนบุคคล)
1. **"คุณอยู่ที่นี่" บนแผนที่** แสดงให้คุณเห็นคนเดียวบนอุปกรณ์ของคุณ และไม่ส่งไปยังเซิร์ฟเวอร์
2. **ปักหมุดตรงที่ฉันยืน** หมุดหลุมบ่อจะบันทึกที่ตำแหน่ง GPS ของคุณพร้อมความแม่นยำ ทุกคนบนเซิร์ฟเวอร์นี้เห็นหมุดได้ จึงรู้ได้ว่ามีคนอยู่ที่จุดนั้นตอนปักหมุด และใครเป็นผู้ปัก
3. **บันทึกการขับ** เส้นทาง GPS จะบันทึกไว้กับวิดีโอ เพื่อวางแบบจำลอง 3 มิติบนแผนที่และให้ขนาดหลุมบ่อตามจริง ผู้ที่อยู่ในบริษัทของคุณและเปิดโครงการได้จะเห็นการสำรวจนั้น
4. **แชร์ตำแหน่งในแชท** เมื่อคุณกดแชร์ตำแหน่ง ระบบจะส่งตำแหน่งของคุณหนึ่งครั้ง แบบเข้ารหัสต้นทางถึงปลายทาง ไปยังผู้ที่อยู่ในแชทนั้น

iScale ไม่ใช้ตำแหน่งของคุณเพื่อจุดประสงค์อื่น ไม่ใช้เพื่อการตลาด และไม่ใช้ตรวจสอบการทำงานหรือเวลาทำงานของคุณ ตำแหน่งปัจจุบันของคุณจะไม่แสดงให้เพื่อนร่วมงานหรือผู้ดูแลระบบเห็น

## สิ่งที่เส้นทาง GPS บอกได้
เส้นทางของการขับแต่ละครั้งแสดงว่าคุณอยู่ที่ไหนและเมื่อใด ตลอดช่วงการขับนั้น

## ผู้รับข้อมูลและสถานที่เก็บ
- ข้อมูลเก็บไว้บนเซิร์ฟเวอร์ iScale นี้ ซึ่งดำเนินการโดย **{controller}**
- เพื่อแสดงชื่อถนนและประเภทถนนของหมุด ระบบจะส่งพิกัดของหมุดโดยไม่มีชื่อของคุณไปยังบริการของ OpenStreetMap (Nominatim และ Overpass ซึ่งให้บริการจากยุโรป) หากผู้ดูแลระบบเปิดใช้ข้อมูลจราจรสด ระบบจะส่งพิกัดไปยัง Google Maps ด้วย เส้นทาง GPS และตำแหน่งปัจจุบันของคุณจะไม่ถูกส่งไปยังบริการเหล่านี้
- หน่วยงานของรัฐจะได้รับข้อมูลเฉพาะเมื่อกฎหมายกำหนดเท่านั้น

## ระยะเวลาการเก็บ
- ตำแหน่งของหมุดเก็บไว้ตราบเท่าที่หมุดยังอยู่ ผู้ปักหมุดหรือผู้ดูแลระบบลบหมุดได้
- เส้นทาง GPS ของการขับเก็บไว้กับการสำรวจนั้น จนกว่าคุณจะลบ (ตั้งค่า ตำแหน่ง ลบเส้นทาง GPS ของฉัน) หรือปิดการใช้ตำแหน่ง หรือมีการลบการสำรวจ
- iScale เก็บบันทึกคำตอบของคุณต่อข้อตกลงนี้ (ยินยอม ไม่ยินยอม ปิดการใช้ พร้อมวันที่) ตราบเท่าที่บัญชีของคุณยังอยู่

## การปิดการใช้ตำแหน่ง
- **ตั้งค่า → ตำแหน่ง → ใช้ตำแหน่งของฉัน: ปิด ได้ทุกเมื่อ** ใช้การแตะครั้งเดียวเท่ากับตอนยินยอม และมีผลทันที
- เมื่อปิด iScale จะหยุดอ่านตำแหน่งของคุณทันที และ**ลบเส้นทาง GPS ของการขับที่คุณบันทึกไว้**
- หมุดที่ปักไว้แล้วยังคงอยู่เป็นบันทึกตำแหน่งหลุมบ่อเพื่อการบำรุงรักษาถนน และการสำรวจ 3 มิติที่ประมวลผลแล้วยังคงตำแหน่งถนนไว้
- การปิดไม่มีผลอื่นต่อบัญชีของคุณ
- เบราว์เซอร์จะขออนุญาตใช้ตำแหน่งด้วย คุณปิดกั้นได้ที่เบราว์เซอร์เช่นกัน

## สิทธิของคุณตาม พ.ร.บ. คุ้มครองข้อมูลส่วนบุคคล
คุณมีสิทธิ:
- ถอนความยินยอม (มาตรา 19)
- เข้าถึงและขอรับสำเนาข้อมูล (มาตรา 30)
- ขอรับข้อมูลในรูปแบบที่ใช้งานได้ (มาตรา 31)
- คัดค้านการใช้ข้อมูล (มาตรา 32)
- ขอให้ลบหรือทำให้ข้อมูลไม่สามารถระบุตัวตนได้ (มาตรา 33)
- ขอให้ระงับการใช้ข้อมูล (มาตรา 34)
- ขอให้แก้ไขข้อมูลให้ถูกต้อง (มาตรา 36)
- ร้องเรียนต่อคณะกรรมการคุ้มครองข้อมูลส่วนบุคคล: complaint.pdpc.or.th โทร 02 111 8800 (มาตรา 73)

หากต้องการใช้สิทธิ ติดต่อ **{contact}** หรือส่งจดหมายถึง **{address}** คำขอจะได้รับการตอบภายใน 30 วัน

## ผู้รับผิดชอบ
**{controller}** เป็นผู้กำหนดการใช้งานเซิร์ฟเวอร์ iScale นี้ และเป็นผู้รับผิดชอบข้อมูลนี้ ติดต่อ: **{contact}** ที่อยู่: **{address}**

การเลือก **ยินยอม** หมายถึงคุณตกลงให้ iScale ใช้ตำแหน่งของคุณตามที่อธิบายไว้ข้างต้น คุณเปลี่ยนใจได้ทุกเมื่อ
